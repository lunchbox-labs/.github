# Repository guidance

Read [common agent guidance](standards/agent-guidance.md). When editing a category standard, also read that file: [workflows](standards/workflows.md), [npm packages](standards/npm-packages.md), or [iOS apps](standards/ios-apps.md).

Keep shared guidance broadly applicable within its category. Put project-specific commands, versions, and exceptions in the adopting repository. Keep the root README as the standards index and `profile/README.md` as the organization profile.

For documentation changes, check relative links, consistency across the index and standards, and `git diff --check`. This repository currently has no build or test suite.
